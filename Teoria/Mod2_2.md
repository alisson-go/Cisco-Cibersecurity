2.2.1 Ingeniería social
La ingeniería social es la manipulación a las personas para que realicen acciones o divulguen información confidencial. Los ingenieros sociales con frecuencia dependen de la disposición de las personas para ayudar, pero también se aprovechan de sus vulnerabilidades.
  1. Pretexto
Esto es cuando un atacante llama a una persona y miente en el intento de obtener acceso a datos privilegiados.
2. Infiltración (tailgating)
Esto es cuando un atacante sigue rápidamente a una persona autorizada a un lugar seguro.
3. Una cosa por otra (quid pro quo)
Esto sucede cuando un hacker solicita información personal de una parte a cambio de algo, como un regalo gratis.

2.2.2 Denegación de servcio
Un ataque DoS da como resultado cierto tipo de interrupción del servicio de red a los usuarios, los dispositivos o las aplicaciones.
* Cantidad abrumadora de tráfico: se envía gran cantidad de datos a una red, host o una aplicación a una velocidad que no puede procesar.
* Paquetes maliciosos formateados: Envio de un paquete (cleccion de datos) con formato malicioso que el receptor no puede manejarlo

2.2.3 DoS distribuido

similar a un ataque DoS pero proviene de múltiples fuentes coordinadas
Ejemplos: 
  * Un atacante crea una red (botnet) de hosts infectados llamados zombies, que son controlados por sistemas de manejo.
  * Las computadoras zombis constantemente analizan e infectan más hosts, creando más y más zombis.
# Botnet
Una computadora bot se infecta generalmente por visitar un sitio web, abrir un elemento adjunto de correo electrónico o abrir un archivo de medios infectado.
Una botnet es un grupo de bots, conectados a través de Internet, que pueden ser controlados por un individuo o grupo malintencionado. Puede tener decenas de miles, o incluso cientos de miles, de bots que normalmente se controlan a través de un servidor de comando y control. Estos bots se pueden activar para distribuir malware, lanzar ataques DDoS, distribuir correo electrónico no deseado o ejecutar ataques de contraseña por fuerza bruta. Los ciberdelincuentes suelen alquilar botnets a terceros con fines nefastos.

Firewall de Cisco:
1. Los bots infectados intentan comunicarse con un host de comando y control de internet
2. El filtro de botnet de Firewall de Cisco es una función que detecta el tráfico procedente de dispositivos infectados con el código botnet malicioso
3. El servicio Cisco Security Intelligence Operations (SIO) basado en la nube envía filtros actualizados al firewall que coinciden con el tráfico de las nuevas botnets conocidas.
4. Las alertas se envían al equipo de seguridad interno de Cisco para notificarles sobre los dispositivos infectados que generan tráfico malicioso para que puedan prevenirlo, mitigarlos y remediarlos.

2.2.4 On-Path (en ruta) Attacks

Los atacantes en ruta interceptan o modifican las comunicaciones entre dos dispositivos, como un navegador web y un servidor web, ya sea para recopilar información de uno de los dispositivos o para hacerse pasar por uno de ellos.

This type of attack is also referred to as a man-in-the-middle or man-in-the-mobile attack.

man-in-the-middle (MITM) --> un ciberdelicuente toma el control de  un dispositivo sin que el usuario lo sepa. Con este nivel de acceso, el atacante puede interceptar y capturar información sobre el usuario antes de retransmitirla a su destino. Estos ataques de usan para robar información financiera

man-in-the-mobile(MITMO) --> ataque usado para tomar el control de un dispositivo móvil. Cuando está infectado, el dispositivo móvil recibe instrucciones de filtrar información. Un ejemplo es el paquete malware ZeUS.
